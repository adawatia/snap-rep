# Exercise catalog source

`free_exercises.json` is the combined dataset from
[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db),
commit `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`.
The upstream project publishes the data under the
[Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md)
(public domain). SnapRep bundles the JSON for offline exercise search and
instruction text. Image paths in the dataset are not loaded by the app.
